# YouTube Video Recommendation Assistant

This project is a simple C++ program created for the **LDCW6113 - Fundamentals of Digital Competence with Basic Programming** group assignment.

## Project Topic

The project is based on **YouTube as a disruptive innovation**.

The C++ program focuses on one important feature of YouTube: allowing users to choose content based on their own preferences.

## Program Purpose

The YouTube Video Recommendation Assistant recommends a suitable type of YouTube video based on the user's choices.

The user selects:

- Preferred video category
- Preferred video length

The program then provides a recommendation.

## Video Categories

The available categories are:

1. Education
2. Gaming
3. Music
4. Technology
5. Lifestyle

## Video Length

Users can choose:

1. Short - less than 5 minutes
2. Medium - 5 to 20 minutes
3. Long - more than 20 minutes

## Programming Concepts Used

This program uses:

- C++
- Variables
- `cin`
- `cout`
- `if / else`
- `switch`
- User input
- Program output
- Basic input validation

## How to Compile

Use the following command:

```bash
g++ youtube_recommendation.cpp -o youtube
```

## How to Run

On macOS or Linux:

```bash
./youtube
```
